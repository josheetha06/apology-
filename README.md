# A Heartfelt Apology 💌

An interactive, editorial apology website featuring an interactive 3D translucent pink vellum envelope, lace heart doily, background music ("Aaruyire Mannippaya"), and an unfolding heartfelt apology letter.

## Features
- **Interactive 3D Envelope**: Opens on scroll with a single-hinged 180° backward flap and embossed wax seal.
- **Semi-transparent Blush Pink Vellum**: Frosted glass aesthetics matching Victorian stationery references.
- **Heartfelt Letter Reader**: Clicking the half-tucked letter opens a dedicated stationery reader modal.
- **Background Song**: Autoplays background music with an interactive toggle button.
- **Delicate Ambient Canvas**: Falling petals and warm glows.
